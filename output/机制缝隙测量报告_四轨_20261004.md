## 七、口径与限制

- A 轨用**免票量**口径（分母 = 二等注数反推票量），对追加/复式/多倍免疫。 「票量 = 总投注额/2」只对双色球成立（二等反推比 1.0041）； 大乐透为 1.1324（追加投注），故其销售额口径 R 不可用于判定。
- A′ 轨只对 排列5 / 七星彩 生效；排列3 / 福彩3D 的销售额覆盖**全部玩法**， Σ注数/Σ(N·p) 量的是投注结构占比（实测三玩法份额 0.6766+0.0829+0.2294≈0.99） 而非缝隙 → 显式降级。七星彩只用现行规则段（≥2020-10-11，组合空间 1.5e7）。
- 标准误一律用**经验离散度**，不用模型隐含方差 （双色球经验 se 0.0203 是模型隐含 se 0.0030 的 6.7 倍）。 A/B/γ 三处口径现已统一为长块 bootstrap；实测真实 u 序列没有可检出的 块结构，长块 se 并不更宽 —— 统一口径是为了可复现，不是为了更保守。
- 原方案里的「条件口径 R_cond」**不是检验**： R_cond = Σy/Σ(N·p1·e^{βz}) 在 q̂=p1·e^{βz}/c 下恒等于 c， 实测在偏置 θ∈[0,4] 上恒为常数（sd=0）。已降级为模型校准诊断。
- B 轨每期分位只用其之前的数据拟合 β（n_leak=0 自检）。 判定用的 se 是**长块移动块 bootstrap 的经验离散度**（与 A 轨同一估计量）； 解析 se=1/√(12n) 假定 u 序列 i.i.d.，**只作参照、不参与判定**。
- C 轨对红球形态设「分段同质闸门」：全样本显著但前半/后半段均值断裂的特征， 一律判为数据/规则分段问题、不参与判定（本次实测见上方线索区）。
- 阈值参与缓存指纹：改 --min-effect / --min-train / --step 会自动重算， 不会静默沿用旧阈值的缓存结果。
- 判定轨只有 A/A′/B；C/D 一律不参与判定。
- 「未检出缝隙」≠「已证明开奖公平」；本报告只给效应量、CI 与判定。

# 机制缝隙测量报告 · 四轨

**日期**：2026-10-03 　**阶段**：P1+P2 完成（检查点交付物）
**复现命令**（一行，6 彩种全跑）：

```
python cli.py gap            # 默认 all；走 cache/mechanism/ 缓存
python cli.py gap --no-cache # 强制重算；单彩种：python cli.py gap 双色球
python cli.py gap --json     # 机器可读
```

**本轮做了什么**：不再检验「开奖是否随机」，改为测量**「开奖中心是否在系统性地避开大众买得多的组合」**这一具体机制，并给出可检出的强度边界。四轨 = 2 条判定轨（A/A′、B）+ 2 条线索轨（C、D）。

---

## 一、一句话结论

> **6 彩种、4 条判定轨，全部与「公平开奖」相容；跨彩种 BH(FDR) 检出：无。**
> 冷门偏置强度 **γ = −0.017 ± 0.124（双色球，CI 含 0）**；大乐透流行度模型未过 Go 门槛，γ **不可折算**。
> 即：**在现有数据量下，没有测到缝隙** —— 这是功效边界，不是「机制不存在」的证明。见 §6。

**符号**
- **R**（注数比）= 实际一等奖注数 ÷ 期望注数。**免票量口径**（分母由二等奖注数反推总票量），对追加/复式/多倍免疫，**完全不依赖任何模型**。R < 1 ⇒ 开奖号比期望更冷。
- **ū** = 真实开出组合在流行度排序中的分位均值。公平开奖 ⇒ 0.5。严格 walk-forward（每期只用其之前的数据拟合，`n_leak = 0` 自检）。
- **γ** = 冷门偏置强度，约定 `g(c) ∝ exp(−γ·z(c))`，**γ > 0 = 偏向冷门**。由 A/B 两轨线性折算合并（标尺 `k_A = 0.0280`、`k_B = 0.0476`，M = 1,107,568）。
- **裁决**：`strong` = 所有判定轨都检出；`weak` = 部分检出；`none` = 都未过门槛；`no-track` = **没有可用的判定轨**（≠ `none`）。

## 三、逐彩种裁决（原文）

- **[双色球]** 判定轨均未过门槛（R=0.993912, ū=0.50135）→ **未检出机制缝隙**。这表示在当前样本量与效应量门控下，开奖注数与真实开出组合的冷门度都与「公平开奖」相容；**不表示已证明公平**。附注：两判定轨**方向不一致**（A 轨说 R<1、B 轨说 ū≥0.5）→ 连方向都不稳定，进一步支持「未见缝隙」。
- **[大乐透]** 判定轨均未过门槛（R=0.975908, ū=0.49581）→ 未检出机制缝隙。附注：C 轨全样本显著但**分段不一致**（数据/规则问题，非机制）。
- **[排列5]** 判定轨均未过门槛（A′ 轨 R=1.030523；数字型无 B 轨分位轴）→ 未检出机制缝隙。
- **[七星彩]** 判定轨均未过门槛（A′ 轨 R=0.991149）→ 未检出机制缝隙。附注：D 轨派奖期样本过小、未检出差异。
- **[排列3] / [福彩3D]** **没有可用的判定轨** → 既不判「有缝隙」也不判「无缝隙」。其销售额覆盖**全部玩法**，注数比只能量出投注结构占比，本轨对它们不适用（理由见 §7）。

**跨彩种 BH(FDR) 检出：无**（只有带判定轨的 4 个彩种进入 BH，`no-track` 彩种不进，避免 m 虚增、校正过松）。

### 线索（不参与判定）

- **[双色球]** 逐年 R 的 Spearman 趋势 p=0.0148（ρ=−0.4913），但预先定死比例的「早期 1.0075 → 近期 0.95」端点对比只有 z=−1.029（|z|<2）→ **幅度不足**，不作为「缝隙随时间出现」的证据。
- **[大乐透]** 逐年 R 极差 0.345，但趋势不显著（Spearman p=0.0677）—— 单年 R 经验 sd ≈ 0.10，此量级极差属正常噪声。
- **[大乐透]** B 轨所用流行度模型 5 折 CV 未过 Go 门槛 → 检验水准正确但**功效低**，其 z 不作强证据（这也是 γ 不可折算的原因）。
- **[大乐透]** C 轨「和值」全样本显著但**分段不一致**（前 95.1607 → 后 88.3301，z=−8.706）→ 数据/规则分段问题，非机制。
- **[大乐透]** C 轨「大号个数」同理（前 2.6539 → 后 2.3821，z=−6.999）。
- **[七星彩]** A′ 轨 6 个奖级独立观测同一机制，R 极差 0.0573、**并非全部 <1** → 互为交叉验证。
- **[七星彩]** D 轨派奖期仅 21 期，可检出 |ΔR| 下限 ≈ **0.3659**（一等口径）→ 未检出差异不等于没有差异。

> ⚠️ 值得单列的一条：**大乐透是唯一两判定轨同向（都略偏冷：R=0.976 < 1、ū=0.496 < 0.5）的彩种**，但两个 CI 都含零值、幅度在噪声内，且其 B 轨模型功效低。若后续要追加数据继续追，它是唯一「方向自洽」的候选对象 —— 但目前**不足以主张缝隙**。

## 六、这个测量排除了什么 / 没排除什么 ⭐

这是本报告最有信息量的一段：CI 不只是「没测到」，它给出**残余空间的上界**。

| 彩种 | 判定轨 | 已排除（95%） | 仍未被排除的冷偏置空间 |
|---|---|---|---|
| 双色球 | A（R） | R < 0.964 | R ∈ [0.964, 1.000]，即偏冷 **≤ 3.6%** 的机制 |
| 双色球 | B（ū） | ū < 0.4903 | ū ∈ [0.490, 0.500] |
| 大乐透 | A（R） | R < 0.9416 | R ∈ [0.942, 1.000]，即偏冷 **≤ 5.8%** |
| 大乐透 | B（ū） | ū < 0.4819 | ū ∈ [0.482, 0.500] |
| 排列5 | A′（R） | R < 0.9710 | R ∈ [0.971, 1.000]，即偏冷 **≤ 2.9%** |
| 七星彩 | A′（R） | R < 0.9753 | R ∈ [0.975, 1.000]，即偏冷 **≤ 2.5%** |

**读法**：以上「残余空间」是**功效边界**——
- 一个强度相当于「每期把开奖号的冷门度压低 5% 以上」的机制，本数据**能**测出来，而它**没被测到**。
- 一个强度只有 1% 的机制，本数据**测不出来**，它可能藏在 [0.99, 1.00] 里 —— 本报告对它**不置可否**。
- 因此：「未检出」是**关于数据与功效的断言**，不是「开奖公平」的断言。

**换算到 γ 标尺**（双色球，模型相关，仅供参考）：`1−R ≈ 0.0280·γ`。CI 含 0（γ = −0.017 ± 0.124）。要让 R 稳定落在 0.96 以下，需要 γ ≳ 1.4 —— 本测量对该量级极敏感，未检出。

## 七、口径与限制

1. **A 轨的票量前提**：「票量 = 总投注额 ÷ 2」**只对双色球成立**（二等反推比 1.0041）；大乐透为 1.1324（追加投注，f ≈ 26.5%）→ 其销售额口径 R **不可用于判定**，故 A 轨用**免票量**口径（分母 = 二等注数反推票量），对追加/复式/多倍免疫。
2. **A′ 轨只对 排列5 / 七星彩 生效**；排列3 / 福彩3D 的销售额覆盖**全部玩法**，`Σ注数 / Σ(N·p)` 量的是**投注结构占比**。内证：其三个玩法份额 `0.6766 + 0.0829 + 0.2294 = 0.9889 ≈ 1` —— 既证明「销售额 = 全部玩法票量 × 2 元」，也**反证**「不能判缝隙」。另有硬证据：福彩3D `直选注数` 自 2022-01 起 100% 为 0 → 注数系已失效。
3. **七星彩只用现行规则段**（≥ 2020-10-11，组合空间 10⁷ → 1.5×10⁷，**整张概率表都换了**）。全段混算会造出「一等 R=1.19 / 三等 R=2.92」的**假信号**，切段后六奖级全部 ≈ 1。注意与既有口径的差别：`data_quality.py` 只切**第 7 位**，A′ 轨必须**整段**切 —— 二者不冲突（一个判边际、一个判全局注数），已由测试锁死同源。
4. **标准误一律用经验离散度 + 长块 bootstrap**，不用模型隐含方差（双色球经验 se 0.0203 是模型隐含 se 0.0030 的 **6.7 倍**；长块用于吸收逐年漂移）。
5. **原方案的「条件口径 R_cond」不是检验**：`R_cond = Σy / Σ(N·p₁·e^{βz})` 在 `q̂ = p₁·e^{βz}/c` 下恒等于 c，实测在偏置 θ∈[0,4] 上恒为常数（sd = 0）。**已降级为模型校准诊断**，不参与判定。
6. **B 轨无前视**：每期分位只用其之前的数据拟合 β（`n_leak = 0` 自检）；用中点秩而非 `count(≤)/M`（后者系统性正偏，方向恰好把缝隙量小）。
7. **C 轨分段同质闸门**：大乐透 2007–2013 段 和值均值 97.2 vs 2014 起 88.5（理论 90.0）→ 全样本 z=+4.2 是**分段伪影**。已核实（财政部 2014-04-08 通知）：2014-05-05 起改的是**奖级/奖金分配**，**号码范围自 2007-05-28 上市起一直是「前区 01-35 + 后区 01-12」** ⇒ 断裂既不能由号码范围、也不能由奖级变更解释 → 判为**数据分段问题**，落地为「实质显著 = 族内 BH ∧ |z|≥3 ∧ |前段−后段| 的 z < 3」。
8. **判定轨只有 A/A′/B；C/D 一律不参与判定。**
9. **「未检出缝隙」≠「已证明开奖公平」**；本报告只给效应量、CI 与判定，不做倾向性措辞。

## 八、对后续阶段（P3–P7）的含义

**数字读出来的事实**：γ ≈ 0（CI 含 0），4 条判定轨全部 `none`，跨彩种 BH 无检出。残余的冷偏置空间上界 ≤ 2.5%~5.8%（视彩种）。

**直接推论**：计划里的 **P4「缝隙内选号接线」** 依赖一个非零的倾斜强度。**在现行证据下，γ ≈ 0 ⇒ 该链路默认会退化为恒等映射（输出与今日逐位一致），实质空转。**

按检查点约定，此处**如实说明并给出选项，不硬凑**：

- **选项 ① 只做 P3，暂停 P4/P5** —— 叙事解绑（把 HONEST_NOTE 等改条件式）照做，选号倾斜链与反馈闭环等出现非零证据再上。
- **选项 ② 仍做 P4/P5，作为「框架就绪」的工程基建** —— 按计划原文的伦理红线实现：**γ = 0 时退化路径与今日逐位一致 + 同 seed 等价测试 + `present=false` 文案黑名单**。价值在于把「一旦有证据就能立刻接线」的管道铺好，且实测证明它今天是零副作用。风险：多写代码但当前零收益。
- **选项 ③ 改换可检验的「特别时期」代理重开线索** —— 现状：D 轨派奖期只有 21 期，可检出下限 |ΔR| ≈ 0.37（极低功效）；地理维度按批准口径未做。若认为「特定地区中奖」是核心机制，需要新的数据源与新的测量设计（例如按省市销量/中奖分布构造对照组），属于**新一轮研究**，不在现计划内。
- **选项 ④ 只做 P6/P7 收口** —— 假设注册 + 覆盖测试放宽 + 全量验收，把本轮成果（四轨测量能力 + 一条可复现命令）固化为交付物，不动选号与反馈层。

> 我的建议（供参考，不代替你决定）：**①+④ 先行**（P3 叙事解绑 + P6/P7 收口，把测量能力交付固化），**P4/P5 暂缓**，除非你希望先把管道铺好（②）。若你判断核心机制在「特定地区/特别时期」（③），那需要先解决数据源问题，而不是先写倾斜链路。

# 回溯登记演示：为什么「先看结果再补登记」不采用

> **本文档的性质**：演示材料，不是结论。2026-10-25 应用户要求，把「如果 v1.5 覆盖历史窗」的渲染方式完整跑出来给人看一次——**只看，不采用**。文中的每一个数字都来自当天已提交的探索性复盘（`output/_tier_review.json`，commit `a398028`），没有为新数字跑任何计算。本文档不进任何结论引用链；实际登记的 v1.5 是**前瞻式**的，见 `config/preregistration.json` 变更日志。

## 2. 回溯登记具体坏在哪（不是泛泛的「不严谨」）

1. **判决方向可以倒着写**。预注册里「预期结论」字段的意义（`_预期结论用途`）是让「检出不被读成意外」。回溯登记时，预期可以照着结果写：双色球 ≥10元 已知 +4.40pp，就写「预期 union_greedy 可识别」；大乐透 ≥四等奖 已知 +0.82pp 边缘，就写「预期边缘」。八格全中，预测成功率 100%——这个 100% 是免费的，因为开卷。
2. **p 值的计算时点无法追认**。BH 校正的 m（家族大小）、α、停止规则都是**在看到 p 之后**才有最终形态的。本次探索性复盘比裸跑数据强的地方在于：分析计划（彩种×目标×口径的 4 比较家族、集中度守门口径）是用户在下任务时事先给定的，v1.2 的两级守门也确实先于结论生效——所以这些数字**作为探索性读数是可信的**。但「可信的探索性读数」≠「确认性检验」：缺的是哈希锁、版本锁、停止规则、预期判决这四样契约件。
3. **「不可判」会被洗成「已检验无效」**。双色球 ≥四等奖 n*=43,539 ≫ 3,519，含义是功效不足。回溯登记给它盖「已登记」章之后，读者会把「不可判」读成「登记过的检验说它没用」——而预注册文件自己写着「不可判 = 功效不足以识别差异，**不等于**策略无效」。标签升级直接篡改这句话的语义。
4. **变更日志没法写**。诚实的日志必须写「发布时已看过结果」——写了，登记的确认力当场作废；不写，日志造假。两条路都是死的，这就是回溯登记在结构上不可能诚实的原因。

## 3. 变更日志对照：回溯版会写什么 vs 实际写了什么

**回溯版（演示，不采用）**——无论怎么措辞都会露馅：

> v1.5：新增 ≥四等奖 目标……（无法在不声明「已观测」的情况下拥有确认力；声明即作废。）

**实际版（前瞻式，已登记）**：

> v1.5（2026-10-25，跑之前登记，确认力仅对未来开奖生效）：新增 `前瞻终点_四等奖` 块……本条发布时，2026-10-25 的探索性分级复盘**已经看过**该目标在历史窗上的读数（双 −0.54pp 不可判、大 +0.82pp 边缘），故本登记的确认力**不覆盖**历史窗；历史窗读数永远挂探索性标签。确认力只对登记之后的开奖生效，预注册预期判决为「不可判」。

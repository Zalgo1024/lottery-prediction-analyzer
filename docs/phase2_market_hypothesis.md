# Phase 2 市场假设研究 —— 诚实结论

> 研究工具：`ev/market_features.py`（只读 loader）+ `ev/market_backtest.py`（信号检验）。
> 复现：`python -m ev.market_backtest`（文本报告）或 `python -m ev.market_backtest --json`（JSON）。
> 测试：`pytest tests/test_market_backtest.py`（14 例，全过）。

## ★ 本文的范围声明（2026-10-22 补，先读这段）

本文的工作是**均匀性 / 随机性 / 公平性检验**，产出的是「新数据在可用粒度下未呈现信号」
这一类**阴性**结论。它是**数据质量与局限性的存档**，本项目**不再沿这个方向继续扩展**
——每多跑一次「再证明一次随机」，对策略本身没有增量信息。

后续工作转到**低拥挤目标策略**：把同一批市场数据（销量 / 奖级注数 / 分省）用于
**拥挤度代理模型的构建与其局限性的量化**，见
[`docs/低拥挤策略_设计与局限.md`](低拥挤策略_设计与局限.md)。
那篇文档承接本文的两条死数据红线（无全国每注购买量、无分彩种分地区下注量），
并在其约束下明确「代理分数」能支持什么、不能支持什么。

## 0. 目标与边界

把 market.db 新增的三类市场维度数据当作**候选特征**，检验它们是否携带可用于选号/
提高中奖率的信号：

1. **出球顺序** `draw.seq_front`（双色球/大乐透/排列5/福彩3D/七星彩 有；排列3/快乐8 无）
2. **头奖分省** `prize_region`（仅双色球/七乐彩/快乐8 有）
3. **分省月销量** `region_sales`（仅「福彩/体彩」两 agency，无彩种维度）

诚实边界（贯穿全模块）：本阶段**只检验「这些新数据是否含信号」**；它不改变 Phase 1 已确立的
「换选号不改单注中奖概率」结论。任何「可预测」结论都不得越过下面的**死数据红线**。

## 1. 死数据红线（核心约束，写在最前）

项目原始假设是「开奖开出全国购买最少的组合」。要直接验证它，需要：

- **全国每注购买量**（哪一注被买了多少次）→ 库里**没有**；
- **每彩种每期分地区下注量**（哪一省哪一期下了多少注）→ 库里**没有**。

`region_sales` 只有「全省福彩/体彩总销量」，既不区分彩种，也没有「哪一期」。因此：

> **「最少购买组合」在现有数据下不可直接求得**，原始缝隙假设仍**未能验证、也未能证伪**。
> Phase 2 只能给出「在可用粒度下，新数据未呈现可 exploited 的信号」这一间接、粗粒度结论。

## 2. 出球顺序（A 均匀性 / B 序列相关 / C 滚动预测）

### 2.1 数据质量发现（重要）：七乐彩 `seq_front` 不是摇出顺序

抽样核验发现，**七乐彩**的中彩网源 `seq_front` 是**整数序排列**（200 行全部升序），并非真实
摇出顺序；双色球/大乐透为真实摇出顺序（0/2 行升序、各位置均值≈理论期望）。因此七乐彩被**排除**
在所有出球顺序检验之外，其早先出现的「位置偏差 / 可预测」均为排序假象，不代表真实摇奖结构。
（注：这一发现同样影响 `market/queries.py` 的 `seq_first_ball`/`seq_position_entropy`——它们在
七乐彩上的「首球分布 / 位置均值」是按排序后号码算的，语义是「排序后第 k 小」而非「第 k 个摇出」，
作描述展示时需注意措辞。）

### 2.2 结论（对真实摇出顺序的彩种：双/大/排5/3D/七星）

| 检验 | 方法 | 结果 |
|---|---|---|
| A 均匀性 | 每位置 χ² + 位置数 Bonferroni 校正（α/n） | 全部与均匀兼容，无物理偏差（如双色球 pos4 原始 p=0.042，校正后不显著；大乐透 pos5 原始 p=0.014，校正后不显著）|
| B 序列相关 | lag-1 Pearson，实操阈值 \|r\|>0.10 | 各位置 \|r\|≤0.10，无可用一阶依赖 |
| C 滚动预测 | 近窗众数预测下一期 vs 理论 1/range（二项精确检验）| 自适应命中率≈理论（双 0.0305 vs 0.0303，p=0.87；排5 0.1022 vs 0.10，p=0.42；3D 0.1007 vs 0.10，p=0.79；七星 0.0929 vs 0.0952，p=0.54；大 0.0287 vs 0.0286，p=0.95）|

**结论**：在真实摇出顺序上，**出球顺序无可利用的预测结构（与公平随机相容）**。若摇奖机/球存在
物理偏差，它小到在可用样本量下（千–四千期）无法检出的量级。

## 3. 头奖分省 vs 分省销量（D）

仅双色球、七乐彩有头奖分省数据。用累计销量与头奖注数比较：

- **Spearman 秩相关**：双色球 ρ≈0.92（p≈0）、七乐彩 ρ≈0.76（p≈0）——头奖注数与全省总销量
  **强正相关**：「卖得多则中得多」，与公平随机一致。
- **χ² 拟合优度**（检验头奖是否严格正比于总销量）显著偏大（双 χ²=1093 df=30；七乐 χ²=2881 df=29），
  但**这是混杂造成的假象**：`region_sales` 是全省福彩/体彩**总**销量，而非该彩种销量，且各省
  人均购彩偏好不同，严格正比本就不成立。它**不能**读作「被安排中奖」证据。

**结论**：在省级汇总粒度下，头奖地区分布与销量一致，**无「特定地区被安排中奖」的直接证据**；但受
数据粒度限制（无分彩种、无每期分地区下注量），也**无力排除**更细的异常。

## 4. 分省销量（E，纯描述）

- 覆盖 2008-01 → 2026-09，共 224 个月，唯一缺口 **2020-02**（疫情停售，源头只发全国数）。
- 福彩累计增速 +150.9%、体彩 +1493.6%（体彩 2008 基数极小）；头部省份稳定为广东/浙江/江苏/山东。
- **明确不构成号码预测**：销量是市场背景（趋势/地区差异），与开奖号码无因果/预测关系。

## 5. 总体诚实结论

现有市场数据（出球顺序 / 头奖分省 / 分省销量）在可用粒度下**均未呈现可 exploited 的选号信号**：
出球顺序公平随机、头奖分布与销量一致、销量仅为描述性背景。与此同时，**关键购买量数据缺失**，
原始「最少购买组合」假设**仍不可直接验证**。

→ **Phase 2 不产出任何新的「可下注策略」**。它确立了：市场维度的新数据只能做描述与公平性粗检，
无法支撑 Phase 3 的「特征模型挑战覆盖基线」——因为根本没有可用特征。Phase 3 是否推进，须等购买量
类数据到位，或用户明确接受「无信号」的结论。

## 6. 与 Phase 1 的衔接

Phase 1（奖级覆盖策略）结论是「小/中 K 下提升『至少中 5 元』率、生产 K 下已饱和」，同样不依赖任何
号码预测。Phase 2 进一步确认：即便接入市场数据，也没有可 exploited 信号来改变这一格局。两者共同
指向同一诚实结论——**选号不改中奖概率，杠杆只在覆盖设计与奖金结构**。下一步若继续，应为 Phase 1 的
「低注数保底」可选模式落地（用 `ev/selection.select_coverage`），而非上复杂模型。

# 低拥挤目标策略 —— 设计与局限（首版：双色球）

> 代码：`ev/popularity_proxy.py`（拥挤度代理层）· `ev/lowcrowd_select.py`（选号器）·
> `ev/lowcrowd_backtest.py`（四臂对照回测）· `prediction/engine.py::_predict_lowcrowd`（生产入口）
> 配置：`config/lowcrowd.json`（三档情景参数）
> 测试：`tests/test_popularity_proxy.py` · `tests/test_lowcrowd_select.py` ·
> `tests/test_lowcrowd_backtest.py` · `tests/test_lowcrowd_isolation.py`
> 复现：`python -m ev.lowcrowd_backtest 双色球`

---

## 0. 一句话定位

在「开奖常规态偏向开出全国购买量最少的组合」这一**假设**下，做一条
**与高频 / 遗漏 / 区间均衡并列的独立研究性选号入口**，并用固定注数、固定预算、
多窗口、多种子的四臂对照回测去检验它到底改变了什么。

**它默认不参与生产出号**（不进轮转、不进权重学习、不进动态注数安全阀），
只有显式 `mode="lowcrowd"` 才出号。战绩页与命中页可按策略单独筛出。

## 1. 拥挤度：为什么只能叫「代理分数」

策略定义 `crowd(c) = 预计总投注量 × 组合受欢迎程度`。
`ev/popularity.py` 的 μ = 票量 × P(奖级) × exp(β·f)，其中 exp(β·f) 正是「受欢迎程度」，
所以 **μ 就是 crowd 的自然度量**（差一个与组合无关的常数 P），`z(crowd)` 取 `z(β·f)`。

★ **循环性（必须写在任何拥挤度数字旁边）**：

> popularity 的 β 是用**一等奖注数**反推的（Poisson GLM，offset = log 票量）。
> 而一等奖注数本身会受开奖选择机制影响 —— 用这个量去估计「谁买得多」，二者存在循环。
> 因此本层输出的**不是**购彩偏好的直接测量，只在同一代理口径下可比；换口径即换结论。

这条声明在代码里是单一真源 `ev/popularity_proxy.py::CROWD_PROXY_CAVEAT`，
会随选号元数据一起落到反馈记录里（`data/feedback.py::_carry_lowcrowd_fields`）。
**任何页面上出现「拥挤度」数字，都必须同时能看到这句声明。**

## 2. 为什么 λ 不能是「纯排序权重」

原始设想是 `draw_score(c) = −λ·z(crowd(c))`，按它降序选号。实测这条链路：

```
ev/selection.py 按「一等奖实得」 eff1 降序排序
eff1 = E[min(cap, 池/(1+X))],  X ~ Poisson(μ)     ← 随 μ 单调【递减】
μ    = 票量 × P(一等) × exp(β·f)                   ← 随拥挤度单调【递增】
⇒  「按低拥挤降序」≡「按一等奖实得降序」≡ 现有净 EV 选号
```

实测 Spearman ρ(eff1, μ) = **−1.000000**（`tests/test_lowcrowd_select.py` 锁定）。
**对任意 λ>0，纯排序选出同一批号 ⇒ λ 是数学上的空操作。**
这与 `docs/机制缝隙_策略层可见性设计.md` 第八节记录的 γ 空操作同源：
乘在排序键上的单调因子，改变不了 argsort 的结果。

### 因此差异化必须来自排序键之外，两个真参数

| 参数 | 作用对象 | λ=0 / λ=1 的退化 |
|---|---|---|
| `gate_q` | 拥挤度分位门控，**改变候选集合** | 请求分位凑不满时按阶梯 (0.20 → 0.35 → 0.50 → 1.00) 放宽，并在元数据里记「放宽次数」 |
| `λ` | 双目标加权 `key(c) = (1−λ)·ĝ(c) + λ·cold(c)`，**改变覆盖与冷门的相对权重** | λ=0 → 纯覆盖（退化成 `select_coverage`）；λ=1 → 纯冷门（退化成净 EV） |

**0 < λ < 1 才是本策略。** `ĝ(c)` 是「新增覆盖键 / 35」，盯的是 **≥10 元通道**
（五等：4 红 或 3 红+1 蓝），每注 35 个键 = C(6,4)=15 个红球 4-子集 + 20 个 (3-子集, 蓝)。

### λ 是情景参数，不是从历史反推的点估计

`config/lowcrowd.json` 保留三档（偏覆盖 λ=0.25 / 中性 λ=0.50 / 偏冷门 λ=0.75），
回测按 **λ ∈ {0, 0.25, 0.5, 0.75, 1} × gate ∈ {0.2, 0.3, 0.5, 1.0}** 全网格跑、
报告按情景分行 —— **不挑单一「最优值」**。生产默认取「中性」的理由是它是
覆盖 ↔ 冷门的中点，**不是**因为它在回测里分数最高。

## 3. 主终点（事前写死，不许事后挑）

| 层级 | 指标 | 为什么 |
|---|---|---|
| **主终点** | 单期平均中奖注数 | 各组合等可能 ⇒ 换选号**不改变**单注中奖概率、也不改变平均中奖次数。**四臂若有显著差异，第一解释是实现缺陷或前视泄漏，而不是「策略有效」** |
| 次终点 | ≥10 元期占比 | 五等（4 红 或 3 红+1 蓝），红球 4-子集空间 C(33,4)=40920，K=200 覆盖率约 7%，**未饱和**，对选号有区分力 |
| 报告项 | ≥5 元期占比 / 净收益 | 六等只要求命中蓝球，K ≥ 50 时 16 个蓝球必被覆盖满 ⇒ 该指标在生产注数下**恒饱和**，只作报告不进判定 |

### ★ 角色分工（哨兵 vs 判据，别读反了）

- **≥10 元期占比 = 判定指标**：这是用户对首版指定的主指标，也是四臂之间唯一有区分力的量，
  本策略能不能站住只看它；
- **单期平均中奖注数 = 哨兵**：它被写在「主终点」位置，是因为它**不该动**
  （各组合等可能 ⇒ 换选号不改变平均中奖次数）。它一旦动了，第一解释是实现缺陷或
  前视泄漏，而不是策略有效。
- **判定顺序**：先看哨兵有没有报警 → 哨兵安静才看 ≥10 元 → 再看跨 seed / 块 bootstrap 是否复现。

### 判定三层

1. **跨 seed 全距 vs 组间差**：组间差 ≤ 跨 seed 全距 ⇒ 判「差异在噪声内」，不主张结论；
   大于则要求**先排查前视泄漏与实现缺陷**，不许直接宣布有效。
2. 块 bootstrap CI，块长 ≥ β 重拟合周期（50 期），否则同块共享 β 会假窄。
3. 逐期配对差符号检验（四臂共享同一批开奖期）。

## 4. 四臂对照

| 臂 | 是什么 | 口径 |
|---|---|---|
| `lowcrowd` | 本策略 | β 走 **walk-forward 块重拟合**（min_train=1200，step=50，不落盘）；拟合失败的块分位为 `None` ⇒ **跳过该块**，不许用相邻块的 β 顶替（那是前向泄漏） |
| `prod_mix` | 生产三策略混合 | 按**冻结均分权重** 1/3 逐期重放（生产权重文件含未来信息，禁用于回放）；`existing` 去重集合跨 K 注共享，与生产 `_dedup_and_record` 一致 |
| `net_ev` | 现有净 EV 选号 | `ev.selection.select_tickets`，冻结 β；打分基准期取窗口**之前**那一期，避免「用本期奖池选号又用本期开奖结算」 |
| `random` | 同池随机对照 | `ev.selection.control_tickets`，同一候选池、同样低重叠约束 —— **唯一差异是「有没有按拥挤度/实得排序」** |

### 口径陷阱 1：红球重叠上限必须是 **3**（生产口径），不是 4

`ev/selection._OVERLAP_CAP["双色球"] = 4`，而生产 `engine._dedup_and_record` 用的是 **≤3**，
`_predict_lowcrowd` 也显式传 `cap=3`。回测若让低拥挤臂默认走 4，就会与生产差一个口径。
实测（窗口 500，K=200，λ=0.5 / gate=0.30，同池同种子）：

| | cap=3 | cap=4 |
|---|---|---|
| lowcrowd ≥10 元期占比 | **0.748** | 0.630 |
| 同池随机 ≥10 元期占比 | 0.812 | 0.800 |

即：放宽重叠 ⇒ 冷序贪心选出的票更聚集 ⇒ 各注中奖事件更正相关 ⇒ 「至少一注 ≥10 元」
的并集概率下降。**用 cap=4 跑出来的差距，混的是 cap 差异而不是选号差异。**
`run_arm` 因此默认 `PROD_OVERLAP_CAP = 3`；`net_ev` 臂无法指定（`select_tickets`
不暴露 cap，内部固定 4），结果里以 `重叠上限` 字段标出。

### 口径陷阱 2：配对符号检验在这个设计下是**反保守**的

`net_ev` / `random` / `lowcrowd`（块内）三臂的票集**只抽一次、跨期复用**。
于是「逐期配对差」看似有 N 期样本，实际有效样本量接近 **1**（票集这一个共同随机冲击）。
p 值会假小。**判定必须以跨 seed 全距为准**，符号检验只作参考。

**四臂逐期对齐**：低拥挤臂的 β 需要 1200 期训练历史，生产臂首期需要历史窗口，
取两者**交集起点**作为公共回放窗口（`run_arm` 返回 `回放起点` / `公共窗口期数`）。
不对齐的话，逐期配对符号检验会被 `zip` 静默截断成对错的期。

## 5. 数据能支持到哪里（局限，与收益同等重要）

**能支持的**

- 双色球 / 大乐透的**销量 + 奖级注数** ⇒ 市场层面的拥挤度**代理**分数；
- 首版只有**双色球**：大乐透 popularity 模型未达 Go 门槛（LRT 显著但 CV 仅 2/5 折优于零模型），
  `pp.go_or_none` 返回 False ⇒ **显式拒绝并给原因，不静默降级成启发式**。

**不支持的（死数据红线，承接 `docs/phase2_market_hypothesis.md` 第 1 节）**

- **没有每组合的实际购买量** ⇒ `crowd(c)` 只能是代理，无法直接验证「最少购买组合」；
- **没有每彩种每期分地区的下注量** ⇒ 「定向让特定地区中奖」这一特别期假设
  **无法映射成号码**，因此**第一版不做地区打分**（做了就是编造的分数）；
- 出球顺序 `seq_front` 只作为额外特征候选，**不与「组合购买量」混为一谈**。

**因此第一版只做常规态**（偏向低购买量组合）；特别期与地区定向留作独立接口，
等「组合 → 地区」的映射真正存在时再开。

## 6. 生产接入程度

| 项目 | 状态 |
|---|---|
| 出号轮转 | **不参与**（dispatch 在三策略轮转之前直接 return，天然跳过轮转补齐与 `_apply_prune`） |
| 权重学习 | **不参与**（`data/feedback.NON_LEARNING_STRATEGIES`；漏掉这行会把三策略权重从 1/3 稀释成 1/6） |
| 动态注数安全阀 / 压缩 KPI | **不参与**（`_recent_hit_stats` / `_last_compress_kpi` 按台账域过滤，且改为**先过滤再截断**） |
| pending 落账 | **独立台账域**：`台账域=研究`，去重键 `(目标期号, 档位, 台账域)` ⇒ 与生产批同期待开奖**共存、互不删除**。CLI / Web 的 `mode=lowcrowd` **默认不落账**（需显式 `--record-pending` / `"record_pending": true`），否则手工用小组数跑会替换掉调度器已写的 200 注研究批 |
| 调度器平行批次 | **已实现，默认关闭**。`config/lowcrowd.json` 的 `启用=true` 后，自动流水线（`web/utils.py` ③a 与 `cli auto` ④a）在同一期额外生成一条研究台账批：固定 200 注、不跟滑轨、失败一律降级不影响生产 |
| 战绩可见性 | 战绩榜 + 命中页均有「策略」下拉；`_strategyBadge` 给 `低拥挤策略` 独立紫色徽标，tooltip 写明「默认不参与生产出号轮换；拥挤度是代理分数，不是真实购买量」 |
| 元数据 | 每期记 λ / 门控（请求与生效分位、放宽次数、门控前后候选数）/ 覆盖键 / β 口径 / 循环性声明；**新增字段不进 `_fb_key` 去重键** |

**容量风险（已知，未消除）**：低拥挤组合在粗特征上是聚集的（共享「跨度大 / 和值高 / 连号少」
等形态），更容易红球重叠。实测（池 20000，K=200，重叠 ≤3）：不门控能出 772 注，
`gate ≤ 0.05` 只出 117 注 ⇒ 四成会落到补齐。默认 `gate_q=0.30` 留了约 2 倍余量，
并有放宽阶梯 + 「从门控幸存者里按冷→热补」的补齐口径（补齐票仍带 `低拥挤策略` 标签）。

## 7. 回测结果

**口径**：双色球；K=200、候选池 8000；红球重叠上限 **3**（生产口径，见 §4 陷阱 1）；
seed 0/1/2；四臂落在**同一批开奖期**（全量窗口公共期数 2306），每期注数四臂均为 200
（由 `test_real_data_four_arms_align_and_no_false_gain` 断言）。

### 7.1 哨兵（单期平均中奖注数）—— 四臂无可复现差异

| 窗口 | lowcrowd | prod_mix | net_ev | random |
|---|---|---|---|---|
| 200 | 13.5217 | 12.9067 | 13.5583 | 13.2633 |
| 500 | 13.3693 | 13.0187 | 13.4273 | 13.3600 |
| 1000 | 13.3620 | 13.3787 | 13.3967 | 13.3743 |
| 全量 2306 | 13.4010 | 13.5296 | 13.4007 | 13.4319 |

全量窗口块 bootstrap CI（块长 50），三臂对同池随机的逐期配对差**区间全部含零**：

- lowcrowd：+0.045 [−0.146, +0.231] / +0.026 [−0.131, +0.188] / −0.164 [−0.359, +0.018]
- net_ev：+0.049 [−0.186, +0.277] / +0.053 [−0.142, +0.243] / −0.195 [−0.405, +0.017]
- prod_mix：+0.149 [−0.182, +0.484] / +0.155 [−0.189, +0.498] / −0.011 [−0.399, +0.355]

窗口 500 同样全部含零。块长换成 200 时有 3 个（每臂各一个）种子翻成不含零，|差| = 0.33~0.43 注/期，
但：lowcrowd 与 net_ev 的差**跨 seed 直接翻转符号**（lowcrowd seed0 +0.376 / seed2 −0.276；
net_ev seed0 +0.330 / seed2 −0.300）；prod_mix 三个种子虽同为负（−0.046 / −0.430 / −0.548），
块长 50 下区间仍全部含零（它逐期重选 ⇒ 期间方差本来就大）。⇒ 判噪声。

⇒ **哨兵没有报警。** 四臂的平均中奖次数没有可复现差异，与「换选号不改变单注中奖概率」一致。

### 7.2 判定指标（≥10 元期占比）—— 差异可复现，但方向是**更差**

| 窗口 | lowcrowd | prod_mix | net_ev | random |
|---|---|---|---|---|
| 200 | 0.7283 | 0.7733 | 0.5600 | 0.8467 |
| 500 | 0.7033 | 0.7907 | 0.5713 | 0.8280 |
| 1000 | 0.7070 | 0.8037 | 0.5753 | 0.8330 |
| 全量 2306 | 0.7077 | 0.8072 | 0.5742 | 0.8245 |

排序在**四个窗口 × 三个 seed 上完全一致**：`random > prod_mix > lowcrowd > net_ev`。
全量窗口块 bootstrap CI（块长 50，三个 seed 全部**不含零**）：

- lowcrowd − random：−0.109 [−0.133, −0.085] / −0.122 [−0.144, −0.100] / −0.120 [−0.141, −0.098]
- net_ev − random：−0.245 [−0.271, −0.219] / −0.248 [−0.270, −0.225] / −0.258 [−0.284, −0.233]
- prod_mix − random：−0.023 [−0.045, +0.001] / −0.010 [−0.034, +0.013] / −0.019 [−0.039, +0.000]（含零）

块长换成 200：`lowcrowd` / `net_ev` 三个 seed 仍**全部不含零**；`prod_mix` 有一个 seed
翻成不含零（[−0.036, −0.002]，贴着边界）⇒ prod_mix 与同池随机的差在噪声边缘，
而 lowcrowd / net_ev 的差**不依赖块长选择**。

**结论：这不是抽样噪声，是结构性差异，而方向不利。** 低拥挤选号把「至少一注 ≥10 元」
的期占比从 0.82–0.85 拉到 0.70–0.73（低 11~13 个百分点）；现有净 EV 选号更极端（0.57）。

### 7.3 为什么：不是「选错了号」，是覆盖并集变小

≥10 元（五等）的判定键是「红球 4-子集」或「(3-子集, 蓝球)」，每注 35 个键。
冷门组合在**粗特征上是聚集的**（共享「跨度大 / 和值偏高 / 连号少 / 不在生日区」这类
不受欢迎的形态），按冷序贪心 + 红球重叠 ≤3 选出来的 200 注，铺开的**不同键更少**
（实测 λ=0 覆盖 6907 键、λ=1 覆盖 6864 键，理论上限 K×35 = 7000）。于是：

- 各注的中奖事件**正相关** —— 一注中，同形态的其它注倾向于一起中；一注不中，大家一起不中；
- **期望中奖注数不变**（期望的线性性不要求独立 ⇒ 这正是哨兵没报警的原因）；
- 但**「至少一注中」的并集概率下降** —— 和的期望 ≠ 并的概率。

在 K=200 这个尺度上，决定 ≥10 元期占比的是「这 200 注铺开了多少个不同的五等键」，
不是「挑中了哪个组合」。**佐证**：把 beam width 从 150 放宽到全池（贪心近似误差降到 0），
覆盖键只从 6907 涨到 7000，≥10 元从 0.748 到 0.754 —— 几乎不动，
说明瓶颈不是贪心的近似误差，而是冷序本身的聚集性。

### 7.4 λ 与门控：对这个差异几乎没有调节力

Tier-2 网格（窗口 500，seed 0/1/2，cap=3）：

| λ | 门控 | 主终点均值（全距） | ≥10 元均值（全距） | 选中覆盖键 | 门控后候选数 |
|---|---|---|---|---|---|
| 0.0 | 0.2 | 13.369 (0.248) | 0.712 (0.022) | 6907 | 1514 |
| 0.0 | 1.0 | 13.369 (0.248) | 0.712 (0.022) | 6907 | 8000 |
| 0.25 | 0.3 | 13.368 (0.198) | 0.714 (0.028) | 6907 | 2340 |
| 0.5 | 0.2 | 13.347 (0.198) | 0.702 (0.020) | 6899 | 1514 |
| 0.5 | 0.3 | 13.369 (0.182) | 0.703 (0.034) | 6900 | 2340 |
| 0.5 | 1.0 | 13.368 (0.198) | 0.714 (0.028) | 6907 | 8000 |
| 0.75 | 0.2 | 13.189 (0.140) | 0.707 (0.014) | 6884 | 1514 |
| 1.0 | 1.0 | 13.273 (0.300) | 0.711 (0.026) | 6864 | 8000 |

λ 从 0 到 1、门控从 0.2 到 1.0，≥10 元只在 **0.702–0.714** 之间移动（跨 seed 全距
0.010–0.036），主终点 13.19–13.37。**两个真参数都调不动这个指标。**

⇒ λ 作为「情景参数」、不从历史反推点估计的处理是成立的：反推出任何一个「最优 λ」
都会落在跨 seed 噪声里。另外注意同为 gate=1.0 时，λ=0（纯覆盖）0.712 与 λ=1（纯冷门）0.711
只差 0.001，而同池随机是 0.828 —— **差距来自「按结构排序」这件事本身，不是来自 λ 的取值**。

### 7.5 净收益：全为负，且臂间差被**一次**高奖级命中决定

全量窗口 = 2306 期 × 200 注 = **461,200 注**，投入 922,400 元：

| 臂 | 总实得 | 净收益 | 单期最大实得 | top1 期占总实得 | ≥5000 元的期数 |
|---|---|---|---|---|---|
| lowcrowd | 220,335 | −702,065 | 3,100 | **1.4%** | 0 |
| prod_mix | 264,133 | −658,267 | 32,338 | 12.2% | 1 |
| net_ev | **464,166** | **−458,234** | **237,441** | **51.2%** | 1 |
| random | 282,346 | −640,054 | 62,656 | 22.2% | 1 |

`net_ev` 看起来比同池随机多赚 18 万，但 **51.2% 的实得来自单独一期**（237,441 元）。
把各臂「实得最大的那一期」剔除后：

| 臂 | 剔除后的总实得 |
|---|---|
| lowcrowd | 217,235 |
| random | 219,690 |
| net_ev | **226,725** |
| prod_mix | 231,795 |

四臂立刻收拢到 **21.7 万 ~ 23.2 万**（极差 1.5 万，约 6%），而且排序也变了。
窗口 500 是同一个现象的反向验证：那一窗里**没有任何一期实得 ≥ 5000 元**，
四臂净收益落在 −150,975 ~ −153,690（极差 2,715 元，1.8%），此时 `net_ev` 是**最差**的
（−153,690）—— **净收益差的符号随一次命中直接翻转。**

量级上这也说得通：461,200 注下二等奖期望命中约 **0.39 次**、一等奖约 0.03 次
（二等奖 P = 15 / 17,721,088）。也就是说「某臂净收益更好」在样本内只需要撞上一次，
撞不撞上基本是运气，**有效样本量远小于 1**。

⇒ 这就是为什么 §3 把净收益定为**报告项**而不是判定指标：
在出现可复现的差异之前，它测的是「谁撞上了那一次」，不是选号质量。

### 7.6 小 K 场景（K ∈ {10, 25, 50}）—— ≥5 元不饱和的那一段

窗口 500、seed 0/1/2、cap=3。括号里是**跨 seed 全距**，用来判断组间差是不是噪声。

**主终点（单期平均中奖注数）**

| K | lowcrowd | prod_mix | net_ev | random |
|---|---|---|---|---|
| 10 | 0.6627 (0.016) | 0.6453 (0.014) | 0.6800 (0.016) | 0.6880 (0.130) |
| 25 | 1.6907 (0.046) | 1.5967 (0.098) | 1.6780 (0.104) | 1.7087 (0.198) |
| 50 | 3.4107 (0.104) | 3.2607 (0.088) | 3.3560 (0.228) | 3.4140 (0.196) |

三个 K 下组间差都 ≤ 跨 seed 全距 ⇒ 无差异；且主终点 ≈ 0.0667 × K（0.66 / 1.69 / 3.41 / 13.37），
**单注期望回报与选号无关**，与 K=200 同一个结论。

**≥5 元期占比（K=200 时恒饱和，小 K 才不饱和）**

| K | lowcrowd | prod_mix | net_ev | random |
|---|---|---|---|---|
| 10 | 0.5593 (0.090) | 0.4733 (0.110) | 0.5147 (0.108) | 0.5267 (0.082) |
| 25 | 0.8620 (0.082) | 0.7680 (0.064) | 0.8907 (0.100) | 0.8373 (0.026) |
| 50 | 0.9707 (0.064) | 0.9227 (0.048) | 0.9720 (0.044) | 0.9820 (0.054) |

确认了 §3 的判断：K=10 时 0.47–0.56（未饱和），K=50 已到 0.92–0.98（接近饱和）。
**但在每个 K 上，四臂差异都不超过各自的跨 seed 全距** ⇒ 噪声内：
K=10 组间差最大 0.086（lowcrowd vs prod_mix）≤ 全距 0.110；
K=25 最大 0.053（net_ev vs random）≤ 全距 0.100；
K=50 最大 0.059（random vs prod_mix）≤ 全距 0.064。

**≥10 元期占比**

| K | lowcrowd | prod_mix | net_ev | random |
|---|---|---|---|---|
| 10 | 0.0673 (0.004) | 0.0767 (0.016) | 0.0633 (0.002) | 0.0660 (0.018) |
| 25 | 0.1567 (0.034) | 0.1733 (0.034) | 0.1333 (0.008) | 0.1867 (0.018) |
| 50 | 0.2733 (0.032) | 0.3300 (0.042) | 0.2340 (0.016) | 0.3353 (0.020) |
| 200 | 0.7033 (0.034) | 0.7907 (0.032) | 0.5713 (0.024) | 0.8280 (0.048) |

排序 `random > prod_mix > lowcrowd > net_ev` 在 **K=25 / 50 / 200 上一致复现**
（K=10 时四臂都在 0.063–0.077，500 期里只有约 35 期命中 ⇒ 事件太稀，区分不出来）。
K=50 上 random − lowcrowd = 0.062 > 两侧全距（0.032 / 0.020）⇒ 与 K=200 同向，仍是**负向**。

**净收益**：四臂全为负，且回报率在各 K 上落在 22.1% / 22.8% / 23.1% / 24.2%
（单注每期实得 0.442 → 0.485 元，随 K 缓慢上升是因为大 K 把蓝球与五等键覆盖得更满），
**四臂之间不因选号而系统性拉开**。

### 7.7 首版结论

1. **哨兵安静**：四臂的单期平均中奖注数无可复现差异，与既有结论「换选号不改变中奖率」一致。
2. **判定指标方向不利**：≥10 元期占比上，低拥挤策略在四个窗口、三个 seed、两种块长下
   **稳定低于同池随机 11~13 个百分点**。这个差异是结构性的（覆盖并集变小，§7.3），
   不是抽样噪声 —— 但它是**负向**的。
3. **不接生产**：与既定设计一致，`低拥挤策略` 保持「独立入口、默认不参与生产出号」，
   不影响现有预测与权重。它保留为**研究性对照入口**，战绩榜与命中页可按策略筛选查看。
4. **不做参数反推**：λ / 门控对这个指标没有调节力 ⇒ 三档情景原样保留，
   不产出「最优 λ」这种看似精确的点估计。
5. **小 K 场景结论一致**（§7.6）：主终点在 K=10 / 25 / 50 上都无可复现差异；
   ≥5 元在 K=10 时确实不饱和（0.47–0.56），但四臂差异全在跨 seed 全距内；
   ≥10 元的 `random > prod_mix > lowcrowd > net_ev` 排序在 K=25 / 50 上复现。
   ⇒ 负向结论**不是 K=200 特有的饱和产物**。
6. **扩大范围暂缓**：在双色球上未看到优于随机的 ≥10 元覆盖能力之前，
   不扩大到大乐透 / 七星彩（§8）。

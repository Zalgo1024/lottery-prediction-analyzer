# 彩票数据源清单（2026-10-21 全量实测）

## 一、四个可用源（按干净程度排序）

### 1. 中国福利彩票官网（福彩官方 · 一手）

```
https://www.cwl.gov.cn/cwl_admin/front/cwlkj/search/kjxx/findDrawNotice
  ?name={彩种}&issueCount=&pageNo=1&pageSize=500&systemType=PC
```

| 参数 | 取值 |
|---|---|
| `name` | `ssq` 双色球 / `3d` 福彩3D / `qlc` 七乐彩 / `kl8` 快乐8 |
| `pageSize` | 实测支持 **500**（单页最大可用值） |

**实测覆盖与深度**：

| 彩种 | 总期数 | 最早可回溯 |
|---|---|---|
| 双色球 | 2078 | 2013-01-01 |
| 福彩3D | 4784 | 2013-01-02 |
| 七乐彩 | 2079 | —— |
| 快乐8 | 2100 | 2020-10-28（首发） |

**字段**（单期）：
`code` 期号 / `date` 开奖日 / `red` 前区 / `blue` 后区 / `sales` 销售额 / `poolmoney` 奖池 /
`prizegrades[{type, typenum, typemoney}]` 各奖级注数与单注奖金 / `detailsLink` / `videoLink`

**★限制**：接口只保留**约 2013 年之后**的滚动窗口，不是全历史。双色球 2003–2012 拿不到。

**★已复核的旧结论仍然成立**：福彩3D 的 `prizegrades` 七个奖级 `typenum/typemoney` **全部为空字符串**
（不是解析问题，是源数据本身缺失）；但 `sales` 正常。快乐8 返回 **39 个奖级**，字段最丰富。

### 2. 中国体育彩票官网（体彩官方 · 一手）

```
https://webapi.sporttery.cn/gateway/lottery/getHistoryPageListV1.qry
  ?gameNo={gno}&provinceId=0&pageSize=100&isVerify=1&pageNo={n}
```

| 参数 | 取值 |

| `pageSize` | 实测 100 可用 |

**实测覆盖与深度（全量，不是滚动窗口）**：

| 彩种 | 总期数 | 最早可回溯 |

**字段**：`lotteryDrawNum` / `lotteryDrawTime` / `lotteryDrawResult` / `totalSaleAmount`（千分位字符串）/
`poolBalance` / `prizeLevelList[{prizeLevel, stakeCount, stakeAmount}]`

**★项目已在用**（`data/fetch_sales.py`）。本轮实测确认：**它是全历史的**，可反向用于校验 500 抓的 CSV。

### 3. 中彩网（中国福利彩票发行管理中心主管 · 二手但结构化）

```
https://jc.zhcw.com/port/client_json.php
  ?transactionType=10001001&lotteryId={id}&issueCount=4000&type=0&pageNum=1&pageSize=4000
```

| 参数 | 取值 |
|---|---|
| `lotteryId` | `1` 双色球 / `2` 福彩3D / `3` 七乐彩 |
| `issueCount` | 实测 **4000 可一次取全**，双色球返回 3517 期 |

**实测覆盖与深度**：

| 彩种 | 期数 | 最早 |
|---|---|---|
| 双色球 | 3517 | **2003-02-23（首期 2003001）** |
| 福彩3D | 1000+ | —— |

**★这是双色球唯一能一次拿全历史的 JSON 源**（福彩官方只到 2013，500 是 HTML 表格需解析）。

**★独有字段（另外三个源都没有）**：

- `seqFrontWinningNum` / `seqBackWinningNum` —— **出球顺序**（非排序后号码）
- `fixPoolMoney` / `fixUBound` / `floatBound` —— 固定奖池与浮动奖封顶
- `winnerDetails[{awardEtc, baseBetWinner{awardNum, awardMoney}}]` —— 逐奖级注数与单注奖金
- `week` / `tryCode` / `djEndTime`

**为什么出球顺序值得单独说**：如果开奖存在物理层面的偏差（球重、机位、摇奖顺序），
它只可能体现在**出球顺序**上，而不体现在排序后的号码集合上。现有四个源里只有这一个提供。

**★限制**：`winnerDetails` 只有奖级，**没有省份/地区**；翻页参数 `pageNum` 实测无效
（pageNum≥5 就返回空），要走 `issueCount` 一次取全。

### 4. 财政部月度全国彩票销售情况（唯一官方"地区"维度）

公告页（每月一篇，URL 形如）：

```
https://zhs.mof.gov.cn/zonghexinxi/YYYYMM/tYYYYMMDD_xxxxxxx.htm
```

页面底部有 `附件.xlsx`，实测可直接下载并用 pandas 解析。通常含 3 类 sheet：

| sheet | 内容 | 粒度 |
|---|---|---|
| 全国彩票销售情况 | 福彩/体彩 × 各玩法 × 当月/累计 | 按月 |
| 分类型彩票销售情况 | 乐透数字/竞猜/即开/基诺/视频 × 同比环比 | 按月 |
| **各地区彩票销售情况** | **31 省 × 福彩/体彩 × 本月/累计 × 销售额+同比** | **按省按月** |

**★这是全行业唯一"官方 + 结构化 + 分省"的数据**。单位万元，31 省全列（含新疆生产建设兵团口径的合计行）。

**★已全量回填**：2008-01 → 2026-09 **共 224 个月 / 13,888 行**（`region_sales`），
每年 12 个月齐全；唯一缺口 **2020-02**（疫情停售，当月只发了全国汇总，源头无分省表）。
抓取已自动化：`python -m market.build --mof-all`（`--mof-months 2026-08,2026-09` 只补指定月），
并已接入每日补库 `DEFAULT_SOURCES`。

**★三个不能写死的点**（都是实测踩出来的）：

1. **sheet 名十年换了四代** —— 2008「计算」/ 2012「Sheet1」/ 2014「Sheet3」/
   2017「XX年X月全国各地区彩票销售情况表」/ 2026「各地区彩票销售情况」。
   写死名字会让 2017 年之前**全部解析为空且不报错**。⇒ 按「首列出现 ≥3 个省级行政区名」自动选表。
2. **早期表头含排版空格** —— 「地　　区」「比上年同 期增长%」，`"地区" in s` 匹配不到 ⇒ 需先压掉所有空白。
3. **同月可能有 3 个附件** —— 必须取「省份行最多」的那份，取第一个会得到 0 行。

**★限制**：只有**销量**，没有"哪个省中了头奖"。它无法直接验证「定向让特定地区中奖」，
只能做**间接检验**：某省销量占比 vs 该省一等奖中出占比，两者长期偏离才有话说。

## 三、对本项目的具体增量（不是泛泛而谈）

1. **双色球可以彻底脱离 500**：中彩网 3517 期一次取全，JSON 直出，不再解析 HTML 表格。
2. **新增 2 个可研究彩种**：七乐彩（官方 cwl，2013 起）、快乐8（官方 cwl，2020-10-28 起，39 个奖级）。
   项目现在只有 6 彩种。
3. **A 轨需要的二等奖注数，官方直出**：双色球 `prizegrades[type=2].typenum`，
   不必再从 500 的表头位置去猜列。
4. **地区维度首次有官方结构化数据**：财政部 xlsx 的 31 省销量。
   可用于「销量占比 vs 一等奖中出占比」的间接检验——但**不能**直接证明定向开奖。
5. **出球顺序是全新的可测量维度**：中彩网独家。现有 `ev/mechanism` 四条轨道全部基于
   **排序后的号码集合**，出球顺序从未被纳入。这是机制假设的一个未开发方向。

## 四、怎么判定"有噪音"（可复用标准）

**可用（零噪音）**：
- 单一职责的 JSON/XLSX 接口，字段有明确语义
- 期号/日期/号码/金额四类字段齐全，可与官方公告逐条对账
- 无广告、无推荐位、无"专家预测"内容

**噪音（不建议作主源）**：
- HTML 表格 / 走势图页面 —— 改版即挂，列顺序靠推断
- 需要 OCR 的图片公告
- 二手聚合站 / 资讯站，同一字段在不同页面口径不一致
- 带"预测""必中""专家推荐"内容的数据站 —— 数据本身可能被加工过
- 只给"最近 N 期"却不说明 N 的接口（无法判断完整性）

**判定动作**：拿到一个源，先取 3 期，与另一个独立源**逐字段对账**（期号、号码、销售额）。
对不上就不是数据源，是参考读物。

## 五、已知坑（实测撞出来的）

1. 福彩官方 `issueStart=2003001` 这种过早期号参数**返回空**（`state=1, total=0`），
   不是"没有数据"而是"超出滚动窗口"。判断深度只能翻页到最后一页看最早期号。
2. 福彩官方 `pageNo` 超出总页数返回 `result: []` 且 `state: 0`——**不报错**。
   按 `len(result)==0` 判结束，不要按 `state` 判。
3. 体彩官方金额字段是**带千分位的字符串**（`"304,050,337"`），直接 float() 会炸。
4. 中彩网 `total` 字段返回的是**本页条数**，不是总期数，别拿它算页数。
5. 中彩网 `pageNum` 实测无效（≥5 返回空），必须用 `issueCount` 一次取全。
6. 福彩3D 的奖级注数在**官方源里也是空的**，三家源都空 ⇒ 别再找替代源，这是源头缺失。

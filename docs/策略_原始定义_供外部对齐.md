## 三、这条策略**不是**什么（交给外部模型时务必先说清）

1. **不是**「预测下一期号码」的模型。原文目标是「在这个缝隙当中来计算出可能的号码」，不是提升命中率。
2. **不是**随机性检验 / 公平性证伪。原文明确排斥这条路线（见第 8 条红线）。项目里此前的「证伪」叙事已按此要求整体改掉。
3. **不是**冷热号、遗漏值、区间均衡那一类统计指标。提出者本人已把遗漏权重归类为「人为自定义统计指标」，与底层机制无关。
4. **不是**只对某一彩种成立。原文用「全国号码」泛指，项目里 6 个彩种都纳入了测量。
5. 「特别地区中奖」这条**目前没有被真正建模**——项目里只有最粗的近似（派奖期 vs 平常期的差异），且统计功效极低。这是原设想里**最大的空白**，不是已完成项。

## 四、项目现状（事实陈述，供接手者判断起点，不必重做）

当前仓库：`github.com/Zalgo1024/lottery-prediction-analyzer`（已公开，AGPL-3.0）。
这条策略在项目里的落地包是 `ev/mechanism/`，门面 `ev/gap.py`，CLI `python cli.py gap [彩种|all]`。

### 4.1 已建成的测量轨道

| 轨 | 内容 | 是否参与判定 |
|---|---|---|
| A | 一等奖注数比：实际注数 / 期望注数（乐透型）。模型无关，主判据 | ✅ 判定 |
| A′ | 数字型注数比（切 2020-10-11 后现行段） | ✅ 判定（仅排列5、七星彩可用） |
| B | 逐期真实开奖号的流行度分位（walk-forward，中点秩） | ✅ 判定 |
| C | 位级/分区结构偏差（多重比较校正后） | ❌ 仅诊断 |
| D | 派奖期 vs 平常期 | ❌ 仅诊断（功效极低） |

- 排列3 / 福彩3D **无判定轨**，输出 `no-track`。注意：这**不等于**「没有缝隙」，是两条不同的断言。
- 票量前提只在双色球成立（二等注数反推比值 1.0041）；大乐透因有追加投注，用「销售额 ÷ 2」会算出假信号，已弃用该口径。

### 4.2 已有结论（截至 2026-10）

- 各彩种 A / A′ 轨点估计：双色球 R≈0.994、大乐透 R≈0.976、排列5 A′≈1.030、七星彩 A′≈0.991。
- 跨彩种 BH 多重比较校正后：**未检出显著缝隙**。
- 因此当前状态下「倾斜强度 γ」全为 0，选号与不倾斜时逐位一致。

### 4.3 已尝试过的「利用」路径及其失败原因（重要，避免重复踩）

- 做法：把机制打分 `ss` 乘进选号排序键 —— `score × exp(-γ·ss)`。
- 发现：选号的排序键「一等奖实得」与机制打分 `ss` 是**同一流行度维度的严格单调函数**（20000 候选上 Spearman ρ = −1.000000）。
  ⇒ 乘一个单调函数**不改变排序**，对任意 γ 都成立。任何 `γ≠0` 的倾斜都改不动最终选出的号。
- 结论：**「机制倾斜」不是可与 EV 选号区分的独立策略**，这是可证明的结构性结论，不是接线错误。

### 4.4 目前唯一能产生真实差异的前瞻对照

`ev/trials.py`（长期在跑，非新建）：
- A 臂 = 按一等奖实得排序出号
- B 臂 = 同一候选池内随机出号
- 每组 100 注，落 `training/trials/<彩种>.jsonl`，开奖后结算，给符号检验 + 序贯 e-value + TOST 等价性。
- 该杠杆**真的产生差异**（A∩B 交集 0~1/20），与 γ 的空转形成对照。

## 五、留给接手者的空白（原设想里尚未被工程化的部分）

1. **「最少人买的组合」如何反推**：目前是从中奖注数反推（模型无关），但如果要真正逐号建模购买分布，需要各奖级注数 + 销售额的逐期数据，且需要处理追加/派奖等口径污染。
2. **「特别时期 + 特定地区」完全没建模**：需要地区级中奖分布数据，项目现在没有。这是原话里最具体、也最未落地的一条。
3. **博弈论形式化**：原话说「怎么运用博弈论的技巧」，项目实际走的是统计测量（假设检验 + 效应量），**没有**用博弈论框架（如开奖方作为对手方的策略优化、机制设计视角）来形式化。这是一块真正的空白。
4. **「算出可能的号码」的落点**：现在只做到「测出缝隙是否存在」，未做到「在缝隙内给出号码集合」。原设想这一步仍缺一个明确的可执行定义（是条件采样？是给定约束下的最优化？）。

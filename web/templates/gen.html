口径说明 这些不是提示文案，是判据

  1. 单期上限的语义是单彩种 · 单批：clamp() 的 n_cap = 单期上限 ÷ 单价，逐彩种、逐批各自取； 跨彩种 / 跨批的总量由月度总额约束，不由这一行约束。
  2. 重出不删除旧号：旧批保留、开奖后照常结算；新批带「重出批号」与旧批分开。 重出不受同期累计约束（这是用户主动再加一套票，不是自动路径加注），但同期累计会出现在批次明细里。
  3. 一致性 ≠ 沉默：有 pending 但组数对不上 ⇒ 标「不一致」并给差额；还没有下一期 pending ⇒ 标「无预测」（开奖后的正常空窗，不是错误）； 生效注数 0 ⇒ 标「停发（预算包络）」，此时重出会得到 0 注，属既定行为。
  4. 截断要披露：出号时若因上限/额度被截断，批次明细里的「补齐统计 · 截断」列会大于 0；它是 0 才表示没被截断。
  5. 读不到就写「—」：接口失败、字段缺失、批次未加载都显示破折号，不显示 0 —— 0 是一个真实读数。

### 任务 1.2：`ev/` 模块 —— 单注净 EV 计算（名义 EV + 限号 EV）✅ 已完成（M2 PASS）

**⚠️ 机制修正（2026-08-25 官方规则核实，财办综[2008]47号 + 体彩官网）**：
原方案"限号→中奖赔付打折"机制**不准确**。实际机制：
- 排列3/福彩3D/排列5 是**固定赔率**（撞号不分薄每注赔付）；限号=某号码投注达动态限额（≈销售额×49%/单注奖金）后**停止销售**，并随销量**滚动放号**——2元小额购彩基本无影响。
- **唯一真实结构性边在七星彩浮动头奖**：一等奖按注数分薄奖池，大众号中头奖被分摊（单注奖金低）、冷门号独享（单注奖金高）。冷门EV > 热门EV 在此彩种上成立。
- 固定赔率彩种 `--cold` 输出 EV 恒定（如 -0.96），这是正确结论而非缺陷：**选号不改变单注期望，只影响大额可购买性**。

**文件**：`ev/rulebook.py`（全奖级赔率+概率）、`ev/crowd.py`（位级热度模型：3D类用直选注数、排列5/七星彩用一等奖注数拟合 β，七星彩含后区0-14）、`ev/engine.py`（`net_ev` 名义EV/限号EV/限号暴露概率 + `scan_issues` 冷门TOP）、`ev/__init__.py`。

**CLI**：
```
python cli.py ev 排列3 --ticket 123        # 单号EV + 限号距离
python cli.py ev 七星彩 --cold 5           # 冷门号TOP（限号EV最高）
python cli.py ev 七星彩 --ticket 0000000   # 大众号撞号修正对比
```

**验收 M2 实测**：①直选名义EV：排列3/3D=−0.96、排列5=−1.0 ✅ ②七星彩冷门0845000 限号EV −1.69 > 热门0000000 −1.84 ✅（撞号修正：头奖单注500万÷(1+9×拥挤分位)）③无数据降级（--issue 不存在 → 名义EV+标注）✅ ④--cold 全彩种可跑 ✅

**⚠️ Rollover 规则修正（2026-02-01 双色球新规，cwl.gov.cn 核实）**：
- 一等奖单注封顶 **1000 万**（非 500 万）；触发封顶 = 一等奖总奖金超 1 亿 → 单注 = 1亿/注数。
- 头奖贡献恒 <1 元（P=5.6e-8×1000万=0.56 元封顶）→ **绝对 EV 阈值无意义**，参与信号改用**相对窗口**：当前头奖单注估计 > 历史 P75。

**P2 关键数学结论（写死）**：所有彩种单注名义 EV 均为负，Kelly 正确输出 = 0（不下注）；Kelly/资金预算用于纪律约束与「负EV不参与」判断，不鼓励下注。
